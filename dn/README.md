# Dos Navigator: чистая переработка фреймворка Turbo Vision

Статус: начало работ, этап D2–D3 (см. `docs/DN-PLAN.md`).

## Структура

- `audit/` — реестр аудита (D3), детекторы совпадений с исходниками TV
- `specs/` — спецификации поведения и интерфейса для переписываемых участков кода (D4)
- `detectors/` — Python/Go скрипты для трёх типов детекторов (A, B, C) из DN-PLAN.md
- `tv-clean/` — переписанная с нуля Turbo Vision (результат D4)

## Подход (clean-room rewrite)

1. **Аудит (D3).** Сравнение исходников DN 1.51 и Turbo Vision (BP7):
   - Нормализация текста (без комментариев, пробелов, с едиными регистром и токенами)
   - Три независимых детектора совпадений (k-граммы, построчное, попроцедурное)
   - Реестр результатов с решениями (переписать/интерфейс/ложное)

2. **Спецификация (D4).** Для каждого совпадения, помеченного "переписать":
   - Описание поведения своими словами (без псевдокода)
   - Интерфейс и граничные случаи

3. **Реализация (D4).** На основе спецификации, без доступа к оригиналу

4. **Перепроверка (D5).** Два независимых прохода детекторов

## Правила

- Исходники DN и TV **не копируются** в репозиторий
- Только наши файлы: скрипты, спецификации, переписанный код, реестр аудита
- Характеризационные тесты (D2) служат эталоном поведения
