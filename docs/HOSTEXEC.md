# Команды хоста из DOS: оверлейный режим

Статус: архитектура и план (задачи T18–T20), кода нет. Ссылки вида §N ведут
в `docs/DESIGN.md`.

## Цель

Набрать в командной строке VC `ls` и увидеть настоящий `ls` того каталога
хоста, который в VC текущий. Как в far2l и mc: панели поверх настоящего
терминала, команда выполняется в нём, её вывод остаётся в буфере терминала.

## Решение

Никакого нового механизма в VC не нужно — всё собирается из того, что уже
есть или делается.

1. **Встроенный `COMMAND.COM`** (`dos/shell.go`, ветка `feat/builtin-shell`).
   VC выполняет команды через `COMSPEC`, то есть через него. Порядок поиска
   команды дополняется одним шагом:
   - внутренние команды (`DIR`, `CD`, …);
   - DOS-программы (текущий каталог, затем `PATH`);
   - **программы хоста** — поиск в `PATH` хоста (`exec.LookPath`);
   - «Bad command or file name».

   Префикс `!` принудительно отправляет команду хосту (`!dir`, `!echo`). DOS
   при совпадении имён побеждает, потому что это DOS-оболочка.
2. **Запуск на хосте.**
   - Командная строка переводится из OEM в UTF-8 и выполняется оболочкой
     хоста: `sh -c` или `cmd /c`. Поэтому конвейеры и шаблоны работают как в
     терминале.
   - Рабочий каталог — каталог хоста, соответствующий текущему каталогу DOS
     (через отображение дисков).
   - Окружение — окружение хоста.
   - Код возврата становится кодом возврата DOS (`INT 21h/4Dh`).
   - `cd` в VC меняет каталог DOS, и следующая команда хоста пойдёт уже туда.
     `!cd` на хосте ничего не даёт: это отдельный процесс.
3. **Оверлей — это режим `console` (§22, `SCREEN.md`) плюс передача
   терминала.**
   - **`console`:** go2dos сбрасывает поток, уходит с альтернативного экрана
     (панели VC скрыты), возвращает терминалу обычный режим и запускает
     команду прямо в настоящем терминале. Цвета, UTF-8, `vim`, `less`, Ctrl-C
     — всё работает как в bash, длинные строки переносит сам терминал. После
     выхода команды go2dos возвращается в сырой режим и альтернативный экран,
     а VC перерисовывает панели после `EXEC`, как делает всегда.
   - **`grid`:** вывод (stdout и stderr) перехватывается, переводится в OEM и
     пишется в хэндл 1 оболочки. stdin берётся из `/dev/null`. Интерактивные
     программы в этом режиме не работают.
4. **Передача терминала — метод интерфейса хоста** (ветка
   `feat/frontend-iface`), например `RunAttached(*exec.Cmd) error`:
   - **ANSI-фронтенд:** чтение stdin должно уметь вставать на паузу, иначе
     заблокированный `Read` украдёт первое нажатие у команды. Поэтому чтение
     идёт через ожидание с таймаутом: `unix.Poll` на Unix, ожидание хэндла
     консоли на Windows — с проверкой флага паузы. Затем `term.Restore`,
     запуск, `term.MakeRaw`, возврат на альтернативный экран;
   - **vtui-фронтенд:** `vtui.Suspend()` / `vtui.Resume()` (`terminal_env.go`
     в vtui).
5. **Безопасность.** Это выход из песочницы, поэтому по умолчанию выключено:
   `Config.HostExec` и флаг `go2dos -host-exec`. Иначе любая DOS-программа
   могла бы запустить что угодно на хосте через `COMMAND.COM /C`. По той же
   причине в WASI preview1 нет запуска процессов (§21).

**Ctrl-O в VC.** Пока VC показывает свой сохранённый «экран пользователя» из
видеопамяти. Настоящий буфер терминала с выводом команд он покажет после API
ролей экрана (`SCREEN.md`, S5/S6) — так же, как в mc и far2l.

## API для других программ

Тот же механизм отдаётся DOS-программам, которые запускают команды не через
`COMSPEC` (например, будущая сборка VC с клавишей «выполнить на хосте»).
Обнаружение через AMIS: `DOS-HOST/HOSTEXEC`. Функция `AL=10h`: DS:SI → блок
параметров с far-указателями на командную строку (ASCIIZ, OEM) и рабочий
каталог DOS (0 — текущий); на выходе AX — код возврата, CF=1 и код ошибки,
если запуск выключен или команда не найдена. Английская спека — вместе с
реализацией.

## Задачи

- **T18 (H)** — запасной поиск команды на хосте во встроенной оболочке,
  префикс `!`, рабочий каталог, режим `grid` (перехват), код возврата,
  `Config.HostExec` и `-host-exec`. Начинать после влития
  `feat/builtin-shell`. Тест e2e: в командной строке VC набрать
  `!echo hostexec-ok` и увидеть строку на экране; `echo` есть на всех ОС.
- **T19 (H)** — оверлей в режиме `console`: метод `RunAttached` интерфейса
  хоста, чтение stdin с паузой в ANSI-фронтенде, `Suspend`/`Resume` в
  vtui-фронтенде. Начинать после влития `feat/frontend-iface`. Тест в pty:
  VC, `!echo hi`, строка `hi` есть в выводе вне альтернативного экрана.
  Стоп-условие: если паузу чтения не удаётся сделать без потери нажатий,
  остановиться и записать в `DOUBTS.md`.
- **T20 (H)** — AMIS-API `DOS-HOST/HOSTEXEC` (после T08) и английская спека.
