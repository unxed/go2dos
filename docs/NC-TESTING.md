# Как проверить Norton Commander в go2dos

Norton Commander в репозиторий не входит; проверяет его владелец копии.
**Прочитайте до конца, прежде чем начинать.**

Что понадобится: Go (версия — в `go.mod`), клон go2dos, каталог с NC.

Блок ниже целиком вставляется в терминал. Он собирает go2dos, сам говорит,
что делать дальше, запускает NC с записью трассы и клавиш и в конце упаковывает
всё для отправки. Две переменные в начале поправьте под себя.

```sh
NC_DIR="$HOME/nc"           # каталог, где лежит NC.EXE
GO2DOS="$HOME/src/go2dos"   # клон репозитория go2dos
(
  set -e
  cd "$GO2DOS" && go build -o /tmp/go2dos ./cmd/go2dos
  OUT="$(mktemp -d /tmp/nc-report-XXXXXX)"
  echo
  echo "== Сейчас запустится NC. Работайте, как обычно."
  echo "== Выход: F10 в NC или Ctrl-] затем q."
  echo "== Если что-то выглядит не так: Ctrl-] затем d (выход с дампом)."
  printf "== Нажмите Enter, чтобы запустить... "; read _
  cd "$NC_DIR"
  /tmp/go2dos -trace "$OUT/trace.jsonl" -record "$OUT/keys.txt" \
    -dump-on-exit -dump-dir "$OUT" ./NC.EXE || true
  tar czf "$OUT.tar.gz" -C "$OUT" .
  echo
  echo "== Готово. Пришлите файл: $OUT.tar.gz"
  echo "== Внутри: трасса вызовов, нажатые клавиши, экран и дамп памяти"
  echo "== (memory.bin содержит и код NC)."
)
```

Если go2dos остановился сам (неподдерживаемая функция или инструкция), дамп
пишется автоматически, а причина печатается последней строкой.

Воспроизвести присланную сессию без терминала:

```sh
go2dos -headless -keys @keys.txt ./NC.EXE
```

## Какие версии NC проверять и как сообщать результат

Достаточно любой одной версии; чем больше — тем лучше. Если есть выбор,
начинайте с 5.0, затем 5.51. Подробнее о версиях и о том, что про них известно, —
в [NC-REQUIREMENTS.md](NC-REQUIREMENTS.md).

| Версия | Основной файл | Зачем | Приоритет |
|---|---|---|---|
| 5.0 (1995) | `NCMAIN.EXE` (~228 КБ), `NC.EXE` (~4 КБ, перезагрузчик) | основная цель | 1 |
| 5.51 (1998, последняя для DOS) | то же | цель; длинные имена только под Windows | 2 |
| 4.0 (1993) | `NCMAIN.EXE` (212 777 байт), `NC.EXE` (3 358 байт) | меньше код, хорошо для разбора | 3 |
| 3.0 (1989) | `NCMAIN.EXE` (139 280 байт), `NC.EXE` — необязательный перезагрузчик | самая простая версия | 4 |

Версии для Windows и OS/2 (Norton Commander for Windows 1.0/2.0, for OS/2) —
не DOS-программы, их не проверяем.

Запускайте и `NC.EXE`, и (отдельным прогоном) `NCMAIN.EXE` напрямую, если они
оба есть: так видно, какую часть работы делает перезагрузчик.

### Чек-лист сценария

Выполняйте по порядку, ничего не пропуская. Запись клавиш и трасса идут
автоматически (блок выше). Если на каком-то шаге что-то не так, не пытайтесь
это обойти: отметьте шаг и переходите к следующему (если NC ещё жив) или
выходите с дампом (`Ctrl-]`, затем `d`).

| № | Шаг | Что должно быть | Отметка |
|---|---|---|---|
| 1 | Запуск `NC.EXE` | появились две панели с файлами каталога, внизу строка клавиш F1–F10 | ок / не ок / упал |
| 2 | Смена панели (`Tab`), вход в каталог (`Enter`) и выход (`..`) | путь в заголовке панели меняется | |
| 3 | `F3` на текстовом файле, затем `Esc` | просмотр показывает текст, `Esc` возвращает в NC | |
| 4 | `F4` на текстовом файле, набрать пару символов, `Esc` (без сохранения) | открылся редактор (`NCEDIT.EXE`), возврат в NC | |
| 5 | `F5` — копирование файла в другой каталог; `F6` — переименование; `F7` — создать каталог; `F8` — удалить | операции выполняются, панели обновляются | |
| 6 | `Ctrl-O` дважды | панели прячутся, виден экран DOS; повторное нажатие возвращает панели | |
| 7 | Мышь: щелчок по файлу, двойной щелчок, щелчок по строке меню, щелчок по строке клавиш внизу | выбор, вход/запуск, меню, действие | пропустите, если мыши нет |
| 8 | Командная строка: набрать `dir` и `Enter`; затем `echo hello` и `Enter`; затем запуск небольшой программы | команда выполняется, результат виден, после неё NC возвращается | |
| 9 | Запуск программы из панели (`Enter` на `.COM`/`.EXE`) | программа запускается и возвращает управление | |
| 10 | Режим 43/50 строк («EGA Lines» в меню настроек), затем обратно | экран переключается и возвращается | пропустите, если пункта нет |
| 11 | `F9` — меню, открыть любой пункт, `Esc` | меню рисуется, закрывается | |
| 12 | `Alt-F1` (выбор диска левой панели), `Esc` | список дисков показан | |
| 13 | `F10`, подтвердить выход | чистый выход в DOS, код 0 | |

### Как сообщить результат

1. Упакуйте каталог отчёта (блок выше делает `.tar.gz` сам).
2. Приложите короткий текст (комментарий в тикете `#1`): версия NC (по экрану
   «About»/«Info» или по имени дистрибутива), какие файлы лежали рядом с
   `NC.EXE`, номера шагов чек-листа с отметкой «не ок»/«упал» и что именно было
   видно на экране (одной фразой).
3. Если go2dos остановился сам, пришлите последнюю строку вывода (там причина) —
   не пересказывайте, а скопируйте.
4. Не присылайте сами файлы NC. Дамп `memory.bin` содержит код NC; если это
   вызывает сомнения, пришлите только `report.txt`, `screen.txt` и `trace.jsonl`.
