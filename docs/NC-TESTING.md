# Как проверить Norton Commander в go2dos

Norton Commander в репозиторий не входит; проверяет его владелец копии.
**Прочитайте до конца, прежде чем начинать.**

Что понадобится: Go (версия — в `go.mod`), клон go2dos, каталог с NC.

Блок ниже целиком вставляется в терминал. Он собирает go2dos, сам говорит,
что делать дальше, запускает NC с записью трассы и клавиш и в конце упаковывает
всё для отправки. Две переменные в начале поправьте под себя.

```sh
NC_DIR="$HOME/nc"           # каталог, где лежит NC.EXE
GO2DOS="$HOME/src/go2dos"   # клон репозитория go2dos
(
  set -e
  cd "$GO2DOS" && go build -o /tmp/go2dos ./cmd/go2dos
  OUT="$(mktemp -d /tmp/nc-report-XXXXXX)"
  echo
  echo "== Сейчас запустится NC. Работайте, как обычно."
  echo "== Выход: F10 в NC или Ctrl-] затем q."
  echo "== Если что-то выглядит не так: Ctrl-] затем d (выход с дампом)."
  printf "== Нажмите Enter, чтобы запустить... "; read _
  cd "$NC_DIR"
  /tmp/go2dos -trace "$OUT/trace.jsonl" -record "$OUT/keys.txt" \
    -dump-on-exit -dump-dir "$OUT" ./NC.EXE || true
  tar czf "$OUT.tar.gz" -C "$OUT" .
  echo
  echo "== Готово. Пришлите файл: $OUT.tar.gz"
  echo "== Внутри: трасса вызовов, нажатые клавиши, экран и дамп памяти"
  echo "== (memory.bin содержит и код NC)."
)
```

Если go2dos остановился сам (неподдерживаемая функция или инструкция), дамп
пишется автоматически, а причина печатается последней строкой.

Воспроизвести присланную сессию без терминала:

```sh
go2dos -headless -keys @keys.txt ./NC.EXE
```

## Копии NC и DN для CI (без участия владельца)

В репозиторий двоичные файлы не входят. CI скачивает их скриптами и проверяет
SHA-256 (задание `e2e-nc-dn` в `.github/workflows/ci.yml`, кэш `actions/cache`).
Если источник недоступен, скрипт завершается кодом 3: шаг CI печатает
предупреждение, `GO2DOS_NC_DIR` / `GO2DOS_DN_DIR` не задаются, тесты NC
пропускаются через `t.Skip`, трассы не снимаются. Несовпадение SHA-256 или
ошибка распаковки — красный шаг.

| Программа | Источник | Что внутри | SHA-256 архива |
|---|---|---|---|
| **Norton Commander 5.51, английский** (на странице — «5.51», 1998; `README.TXT` на дискете 1: «NORTON COMMANDER Version 5.5», Copyright 1998 Symantec) | `http://old-dos.ru/dl.php?id=2256` со страницы `http://old-dos.ru/files/file_1458.html` («Norton Commander.ver.5.51.English.rar», 2 779 709 байт); запасной — Вебархив `http://web.archive.org/web/2id_/http://old-dos.ru/dl.php?id=2256` (та же сумма) | RAR 2.9 с тремя образами дискет `NC551_1..3.IMG` (по 1 474 560 байт). Из образа 1 (FAT) `tools/fetch-nc.sh` берёт `NC.EXE` (3 870 байт, перезагрузчик), `NCMAIN.EXE` (264 602), `NCEDIT.EXE`, `NCZIP.EXE`, `NCFF.EXE`, `NC.HLP`, `README.TXT` и др. без сжатия; образы 2 и 3 (просмотрщики, заставки в сжатом виде) не распаковываются | `eac55480eadd2d71983d465988ad26bd2916904f2483e624c5f7059b16778ef0` |
| **Dos Navigator 1.51** (RIT Research Labs, 1999-04-19; `README.TXT` разрешает бесплатное использование и распространение при условиях BSD-типа с рекламным пунктом) | `https://ritlabs.com/download/dn/dn151.zip` (перенаправляет на `download.ritlabs.com`, 786 272 байт); запасной — Вебархив `web.archive.org/web/20040530102908id_/http://www.ritlabs.com/download/dn/dn151.zip`; исходники той же версии — `dn151src.zip` рядом (не скачиваются) | `DN.COM` (1 778 байт, запускающая программа), `DN.PRG` (MZ, 109 613), `DN.OVR` (оверлей, 745 951), `DN.LNG/.DLG/.HLP`, `DNRUS.*`, каталоги `ENG`, `RUS`, `CD`, `COLORS`, `SSAVERS`, `XLT` | `f6dee3904945a2f390f8576a5d18d83446f4554e43d6f0a3c75f8aa5b570d7d9` |

Суммы обоих архивов совпали у копий из Вебархива. Для RAR 2.9 `7z` 23.01 не
годится («Unsupported Method»); в CI ставится `unrar` из Ubuntu (`apt-get install
unrar` на `ubuntu-latest` отработал), образ дискеты читает `7z`. Локально:
`sh tools/fetch-nc.sh .cache/nc` (получится `.cache/nc/5.51`; нужны `unrar` или
`unar`, и `7z`), `sh tools/fetch-dn.sh .cache/dn` (получится `.cache/dn/1.51`).

Norton Commander 5.0 из скрипта убран: на странице он не последний. Данные
запусков, снятые с 5.0 (прогон 36827208256), **более не актуальны** и
заменены ниже; для справки: у 5.0 тоже был останов на `INT 10h AH=FFh`.

### Наблюдения: запуск NC 5.51 и DN 1.51 в CI

Снято `tools/trace-nc-dn.sh` в прогоне
<https://github.com/unxed/go2dos/actions/runs/36828762885> (задание `e2e-nc-dn`,
<https://github.com/unxed/go2dos/actions/runs/36828762885/job/110260309627>).
Трассы (`*.trace.jsonl.gz`), экраны, дампы и `summary.txt` — в артефакте
`nc-dn-traces` этого прогона (в репозиторий не входят). Для каждой программы по
три запуска, `-headless`, лимит 40 с: без клавиш (`boot`); со скриптом клавиш
(`keys`: пауза 5 с, `Tab`, `Tab`, `F9`, `Esc`, `F10`, `Enter`); то же с
`-lenient` (`lenient`). Ниже — только то, что видно в выводе; причины не
установлены, если не сказано иное.

**NC 5.51, `NC.EXE` и `NCMAIN.EXE` по отдельности (результат одинаков).** Без
`-lenient` останов на первом неподдерживаемом вызове:

```
go2dos: stopped at F000:061E: F000:061E [FE 38 03 01 CF FE 38 04]: unsupported: INT 10h AH=FFh
```

Экран к этому моменту: «The Norton Commander Version 5.5, Copyright (C) 1986 -
1998 by Symantec Corporation.» и `C:\>`. Вызов — `INT 10h`, AX=FF04, BX=0E66,
CX=0E60, ES=B800; для `NC.EXE` — из `2674:0301`, 267-я запись трассы, для
`NCMAIN.EXE` — из `2518:0301`, 254-я запись.
(**Предположение, не проверено по RBIL:** AH=FFh — расширение DESQview/TopView
«обновить видеобуфер»; ES=B800 этому не противоречит.)

С `-lenient` NC доходит до конца: 31 920 записей трассы (`NC.EXE`), итог
```
go2dos: exit code 0
go2dos: unsupported calls answered in lenient mode:
   219 x int10: INT 10h AH=FFh (first at 2674:0301, last at 2674:0301)
```
(`NCMAIN.EXE`: то же, 219 раз, из `2518:0301`.) В экранах, которые печатает
скрипт (`<screen>`), видна одна панель с файлами каталога в правой половине
экрана (`C:\`, `SUBDIR`, `install cfg`, … `nczip msg`, `packer set`, `readme
txt`, `whats new`); левая половина занята заставкой (почему не две панели, не
исследовано); нижняя строка `1Help 2Menu 3View 4Edit 5Copy 6RenMov 7Mkdir
8Delete 9PullDn 10Quit` и после `F9` строка меню `Left Files Disk Commands
Right`; `F10` + `Enter` завершают NC кодом 0. Других неподдерживаемых вызовов в
этом сценарии нет. Не проверено: просмотр, редактор, F5–F8, мышь, режимы 43/50
строк — сценарий их не выполнял (пункты 3–12 чек-листа выше не пройдены).

**DN 1.51, `DN.COM`.** Без `-lenient`:

```
go2dos: stopped at F000:062D: F000:062D [FE 38 06 01 CF FE 38 07]: unsupported: INT 15h AH=10h
```

Экран к этому моменту: «Dos Navigator  Version 1.51  Copyright (C) 1991-99 RIT
Research Labs» и «WARNING: Not enough file handles. Set at least FILES=20 in
your CONFIG.SYS file.» (сообщение печатает DN; почему он считает, что хэндлов
мало, не исследовано). Вызов — `INT 15h`, AX=1022, DX=5019, DS=ES=326E, из
`0322:04B5`, последняя (106-я) запись трассы `dn-boot`.

С `-lenient` DN поднимается: в итоге два неподдерживаемых вызова —
```
     1 x int15: INT 15h AH=10h (first at 0322:04B5, last at 0322:04B5)
     1 x int10: INT 10h AH=1Ch (first at 0322:09B9, last at 0322:09B9)
```
(`INT 10h AH=1Ch`: AX=1C00, CX=0007, BX=4B00; **предположение из памяти о RBIL:**
стандартное VGA «сохранить/восстановить состояние видео».) Экран: две панели
файлов с рамками, строка клавиш `F1 Help F2 User F3 View F4 Edit F5 Copy F6 Ren F7
MkDir F8 Del F10 Menu`, строка меню `≡ File Disk Utilities Panel Manager Options
Window` и часы. Сценарий клавиш был рассчитан на NC: после `F10`, `Enter` в DN
открылось системное меню (`≡`), до выхода дело не дошло, запуск закончился по
лимиту времени («go2dos: timeout»; трасса — около 184 тысяч записей, почти все —
опрос `INT 10h AH=03h/01h/02h` и `INT 16h AH=11h`). Остальные функции DN
(просмотр, редактор, копирование и т. д.) не проверялись.

**Список неподдерживаемого, найденного этими запусками** (реализация не
сделана — только фиксация):

| Программа | Вызов | Откуда | Раз |
|---|---|---|---|
| NC 5.51 | `INT 10h AH=FFh` | `2674:0301` (`NC.EXE`), `2518:0301` (`NCMAIN.EXE`) | 219 |
| DN 1.51 | `INT 15h AH=10h` (AX=1022) | `0322:04B5` | 1 |
| DN 1.51 | `INT 10h AH=1Ch` | `0322:09B9` | 1 |

Неподдерживаемых инструкций ЦП эти запуски не показали (останов был только на
вызовах BIOS). Оговорка по сценариям выше в этом файле: в блоках с `Tab`, `F10`,
`..` без угловых скобок записаны не в формате `keys` (`<Tab>`, `<F10>`); использованный
в CI сценарий написан по `keys/keys.go`.

## Какие версии NC проверять и как сообщать результат

Достаточно любой одной версии; чем больше — тем лучше. Если есть выбор,
начинайте с 5.51 (её берёт CI), затем 5.0. Подробнее о версиях и о том, что про них известно, —
в [NC-REQUIREMENTS.md](NC-REQUIREMENTS.md).

| Версия | Основной файл | Зачем | Приоритет |
|---|---|---|---|
| 5.0 (1995) | `NCMAIN.EXE` (~228 КБ), `NC.EXE` (~4 КБ, перезагрузчик) | цель | 2 |
| 5.51 (1998, последняя для DOS) | то же | основная цель (последняя; в CI); длинные имена только под Windows | 1 |
| 4.0 (1993) | `NCMAIN.EXE` (212 777 байт), `NC.EXE` (3 358 байт) | меньше код, хорошо для разбора | 3 |
| 3.0 (1989) | `NCMAIN.EXE` (139 280 байт), `NC.EXE` — необязательный перезагрузчик | самая простая версия | 4 |

Версии для Windows и OS/2 (Norton Commander for Windows 1.0/2.0, for OS/2) —
не DOS-программы, их не проверяем.

Запускайте и `NC.EXE`, и (отдельным прогоном) `NCMAIN.EXE` напрямую, если они
оба есть: так видно, какую часть работы делает перезагрузчик.

### Чек-лист сценария

Выполняйте по порядку, ничего не пропуская. Запись клавиш и трасса идут
автоматически (блок выше). Если на каком-то шаге что-то не так, не пытайтесь
это обойти: отметьте шаг и переходите к следующему (если NC ещё жив) или
выходите с дампом (`Ctrl-]`, затем `d`).

| № | Шаг | Что должно быть | Отметка |
|---|---|---|---|
| 1 | Запуск `NC.EXE` | появились две панели с файлами каталога, внизу строка клавиш F1–F10 | ок / не ок / упал |
| 2 | Смена панели (`Tab`), вход в каталог (`Enter`) и выход (`..`) | путь в заголовке панели меняется | |
| 3 | `F3` на текстовом файле, затем `Esc` | просмотр показывает текст, `Esc` возвращает в NC | |
| 4 | `F4` на текстовом файле, набрать пару символов, `Esc` (без сохранения) | открылся редактор (`NCEDIT.EXE`), возврат в NC | |
| 5 | `F5` — копирование файла в другой каталог; `F6` — переименование; `F7` — создать каталог; `F8` — удалить | операции выполняются, панели обновляются | |
| 6 | `Ctrl-O` дважды | панели прячутся, виден экран DOS; повторное нажатие возвращает панели | |
| 7 | Мышь: щелчок по файлу, двойной щелчок, щелчок по строке меню, щелчок по строке клавиш внизу | выбор, вход/запуск, меню, действие | пропустите, если мыши нет |
| 8 | Командная строка: набрать `dir` и `Enter`; затем `echo hello` и `Enter`; затем запуск небольшой программы | команда выполняется, результат виден, после неё NC возвращается | |
| 9 | Запуск программы из панели (`Enter` на `.COM`/`.EXE`) | программа запускается и возвращает управление | |
| 10 | Режим 43/50 строк («EGA Lines» в меню настроек), затем обратно | экран переключается и возвращается | пропустите, если пункта нет |
| 11 | `F9` — меню, открыть любой пункт, `Esc` | меню рисуется, закрывается | |
| 12 | `Alt-F1` (выбор диска левой панели), `Esc` | список дисков показан | |
| 13 | `F10`, подтвердить выход | чистый выход в DOS, код 0 | |

### Как сообщить результат

1. Упакуйте каталог отчёта (блок выше делает `.tar.gz` сам).
2. Приложите короткий текст (комментарий в тикете `#1`): версия NC (по экрану
   «About»/«Info» или по имени дистрибутива), какие файлы лежали рядом с
   `NC.EXE`, номера шагов чек-листа с отметкой «не ок»/«упал» и что именно было
   видно на экране (одной фразой).
3. Если go2dos остановился сам, пришлите последнюю строку вывода (там причина) —
   не пересказывайте, а скопируйте.
4. Не присылайте сами файлы NC. Дамп `memory.bin` содержит код NC; если это
   вызывает сомнения, пришлите только `report.txt`, `screen.txt` и `trace.jsonl`.
