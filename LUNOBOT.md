# Инструкции для Лунобота-1 (node 91d86915909d88ed7991a74c)

Управление тестированием и интеграцией с CI для агентов автономного флота (Лунобот-1).

## Интерактивное тестирование в CI (T-03)

Для тестирования интерактивных сценариев (key test spike T-03) используется облачное окружение
без локального терминала:

### Способ: vmlab (unxed/sandbox)

- **Окружение:** [unxed/sandbox/vmlab](https://github.com/unxed/sandbox/tree/main/vmlab)
- **Принцип:** запускать интерактивное тестирование полностью в GitHub Actions CI
- **Процесс:**
  1. Запустить виртуальную машину в CI
  2. Сделать screenshots приложения во время теста
  3. Отправлять нажатия клавиш прямо в VM через CI (без локального терминала)
  4. Собирать результаты (скриншоты, логи, трассы) в артефакты

### Преимущества

- Не требует локального интерактивного терминала на машине разработчика
- Полная воспроизводимость тестов в CI
- История всех нажатий клавиш и скриншотов сохраняется в артефактах GitHub Actions
- Упрощает отладку: можно перезапустить тест в облаке вместо локального воспроизведения

### Реализация

Тесты T-03 (и аналогичные интерактивные сценарии) должны запускаться через vmlab
в GitHub Actions, с сохранением скриншотов и логов клавиатурных событий.
Путь для интеграции: `.github/workflows/` с использованием `unxed/sandbox@main`.
